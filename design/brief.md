## 2. 플로우

### 시나리오 1 — 시험지 한 장 풀기
1. 홈에서 진행 중 세션 카드 또는 자료실에서 회차 카드를 탭한다 (①)
2. 시험지가 열리고 남은 시간이 돌기 시작한다 (②)
3. 지문을 스크롤하며 읽고 펜으로 밑줄을 긋는다 (③)
4. 선지를 고르면 즉시 정오가 붙는다 (④)
5. 제출을 누르면 결과 화면으로 간다 (⑤)

- 사용자 반응 원문: (미수집)
- 반영: 없음
- 화면별 primary CTA: 로그인 → ① · 홈 → ① · 자료실 → ① · 저장 → ④ · 복습 → ⑤ · 마이 → ⑥ · 시험지 → ④ · 퀴즈 플레이 → ③ · 결과 → ⑤ · 퀴즈 결과 → ⑤

### 시나리오 2 — 오늘의 퀴즈
1. 홈에서 퀴즈 카드를 탭한다 (①)
2. 스택 화면으로 퀴즈 세트가 열린다 (②)
3. 선지를 고르면 즉시 정오가 붙고 다음 문제로 간다 (③)
4. 10문제를 다 풀면 퀴즈 결과가 뜬다 (④)
5. 틀린 문항을 확인하고 홈으로 돌아간다 (⑤)

- 사용자 반응 원문: (미수집)
- 반영: 없음

### 시나리오 3 — 첫 실행과 둘러보기
1. 앱을 열어 로그인 화면에서 카카오 로그인을 누른다 (①)
2. 홈 탭으로 진입한다 (②)
3. 자료실 탭에서 회차 카드의 북마크를 누른다 (③)
4. 저장 탭에서 방금 북마크한 카드를 확인한다 (④)
5. 복습 탭의 빈 상태를 본다 (⑤)
6. 마이 탭에서 계정과 로그아웃을 확인한다 (⑥)
