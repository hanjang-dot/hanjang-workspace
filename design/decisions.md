# Decisions

- 사용자 반응 원문: "전부 다 괜찮은 것 같아. 다만 Expo니까 네이티브 UI를 사용해줬으면 해. Stack 같은 거 적극 사용하고"
- 해석: 퀴즈 미리보기(quiz-preview.html, 바이올렛 계열 라이트 디자인) 방향 전체 승인. 해당 시안의 시각 특성을 5축 선택값으로 매핑.
- 구현 지시: 네이티브 UI 우선 — Expo Router native Stack, 네이티브 탭바/헤더, 플랫폼 기본 전환·시트 사용.

### 축 1 — 밝기·색온도

- 선택값: A — 밝은 라이트 배경 (퀴즈 시안 기준 #F6F4FB 계열, 쿨톤 화이트)
- 가장 좋은 것: A
- 근거: 퀴즈 미리보기 승인. 종이 바탕(기존 UI) 배제 — 신규 리디자인 지시.

### 축 2 — 정보 밀도

- 선택값: B — 중간 밀도
- 가장 좋은 것: B
- 근거: 퀴즈 시안의 카드 간격·여백 수준 승인.

### 축 3 — 형태

- 선택값: C — 큰 라운드 (카드 20px+, 버튼 16px, pill)
- 가장 좋은 것: C
- 근거: 퀴즈 시안의 큰 라운드 카드·pill 칩 승인.

### 축 4 — 강조색 성격

- 선택값: A — 비비드 계열 단일 액센트 (바이올렛 #6C5CE7 → #8F7BFF 그라데이션)
- 가장 좋은 것: A
- 근거: 퀴즈 시안의 바이올렛 액센트 승인. 정답 초록·오답 빨강은 상태색으로 별도 유지.

### 축 5 — 타이포 성격

- 선택값: B — 제목·문항 세리프(Noto Serif KR), UI·본문 고딕(IBM Plex Sans KR)
- 가장 좋은 것: B
- 근거: 퀴즈 시안에서 문항만 세리프로 쓴 조합 승인.

## 네이티브 UI 지시

- Expo Router native Stack 네비게이션 적극 사용 (스택 푸시 전환, 네이티브 헤더)
- 탭바는 네이티브 탭 컴포넌트
- 모달·시트는 플랫폼 기본 프레젠테이션 (formSheet 등)
- 웹식 커스텀 크롬(자체 헤더바 등) 최소화
