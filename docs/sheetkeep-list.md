# SK-E2 시험지 목록에서 골라 시험을 연다

이 경험은 목록의 기본 기능이다. 기본 실행은 서로 다른 시험지 20장이다. 200장·중복 페이지·큰 표지는 그 목록이 죽거나 멈추지 않게 잠그는 테스트다. LegendList 데모가 아니다.

프로젝트: SheetKeep  
경험: 2/2  
공고: 슬링 React Native  
레벨: L3

회사 밀착: 필수. 이 경험의 주어는 **시험지**다. 수능·모의·공무원 카드. 상품 피드, 관심종목, “LegendList 데모”면 폐기.

리스트 구현은 `@legendapp/list` LegendList. 수단이다. FlatList 금지. dadamjang 코드 복사 금지.

## 회사 밀착 실패 조건

아래면 SK-E2 미완료다.
- README 첫 줄이 라이브러리 이름
- 카드 데이터가 productId / ticker
- 측정 문장이 “리스트를 최적화했다”로 끝나고 시험지 고르기가 없음
- 표지가 일반 placeholder이고 시험지 표지 fixture가 아님

## 오르조에서 나는 실패

수험생이 오르조에서 시험지를 고른다. 카드는 `2026 수능 국어 짝수형`, `6월 모의 국어`, `공무원 한국사`처럼 생긴다. 각 카드에 시험지 표지가 있다.

서버 페이지가 같은 시험지 ID만 주면 목록 길이가 안 늘고 다음 시험지가 안 나온다. 행만 줄이고 표지를 전부 올리면 갤탭에서 목록이 죽는다. 시험지를 못 연다.

## 프론트 코드로 증명하는 것

시험지 카드를 보이는 만큼만 살리고, 같은 시험지가 두 번 안 열리게 하고, 화면 밖 표지는 메모리에서 뺀다.

구현 수단: LegendList `recycleItems`, `estimatedItemSize`, `keyExtractor=examId`.

## 병목 fixture

- 시험지 200개. 제목은 수능/모의/공무원/자격증 패턴
- 연속 3페이지가 전부 같은 examId
- 큰 시험지 표지 PNG
- 새 시험지가 붙어도 스크롤 위치가 다른 시험지로 점프하지 않음

## 해결

examId로만 카드를 구분한다. 이미 본 시험지는 안 그린다. unique가 0이면 다음 시험지 페이지를 예산 5 안에서 받는다. 표지는 보이는 시험지 카드만 decode한다.

## 기술

1. LegendList + recycleItems. 키는 examId
2. cursor. 페이지 번호에 의존하지 않음
3. 카드 탭은 스크롤 slop 이후. 시험지 세션으로 진입
4. 표지 load 카운터. recycle된 카드는 decode 취소
5. footer는 다음 시험지 요청 중만

## 측정

| 항목 | 통과 |
|---|---|
| 시험지 200개 첫 화면 마운트 | 화면 안 + recycle 윈도우 이하. 전부 올린 ScrollView와 숫자 비교 |
| 중복 시험지 3페이지 | 다음 다른 examId 카드가 이어짐 |
| 자동 요청 | ≤ 5 |
| 스크롤 점프 | 다른 시험지로 안 튐 |
| 표지 decodingCount | ≤ 보이는 시험지 카드 |
| 화면 밖 examId 표지 decode | 0 |

“LegendList가 빠르다”는 완료 문장이 아니다. 시험지를 고를 수 있는지가 완료 문장이다.

## 테스트 / CI

CI job `sheet-list`. fixture 이름은 시험지 제목.

## 완료

수험생이 중복 페이지 뒤에도 다음 시험지를 고를 수 있고, 표지 때문에 목록이 죽지 않아야 완료.  
라이브러리를 FlatList로 바꿔 통과시켜도 미완료. 표지를 전부 올려 통과시켜도 미완료.
