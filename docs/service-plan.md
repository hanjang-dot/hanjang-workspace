# 한장 — 서비스 기획서

슬링(오르조) 지원용 실제 서비스. 오르조 전체가 아니라 **시험지 한 장을 펼쳐 푸는 루프**만 제품으로 둔다.

---

## 1. 한 줄

수능·내신 기출을 태블릿에서 한 장씩 고르고, 지문을 읽고, 밑줄 치고, 선지를 고르고, 채점하고, 끊어도 같은 장으로 돌아온다.

---

## 2. 오르조와의 관계

오르조가 푸는 문제: 종이 시험지를 태블릿+펜으로 바꾸는 것.

한장이 가져가는 한 조각:

| 오르조 | 한장 |
| --- | --- |
| 시험지 고르기 | FO 목록 |
| 지문/문항 한 화면 | FO 시험지 |
| 스마트펜 밑줄 | FO 필기 overlay |
| 바로 채점 | FO 채점 + 서버 정답 |
| 긴 시험 중 앱 전환 | FO 세션 복원 |
| 콘텐츠 운영 | BO 시험지·문항·정답 발행 |
| AI 코치, 오르조 클래스, 성인 시험, 28만 장 | 안 함 |

복제는 하지 않는다. 평가원·교육청 공개 기출과 BO가 올린 시험지만 쓴다. 오르조 콘텐츠를 긁지 않는다.

---

## 3. 사용자

| 앱 | 누구 | 하는 일 |
| --- | --- | --- |
| FO | 수험생 | 회차를 고르고 한 장을 시간 안에 푼다 |
| BO | admin | 시험지 이미지, 문항, 선지, 정답, 퀴즈를 올리고 발행한다 |
| MCP | admin | 같은 문항·퀴즈 추가를 MCP 도구로 한다 |

계정은 수험생(User)은 카카오·전화, admin은 아이디·비밀번호. 둘은 다른 테이블이다. demo-backend 인증을 한장 도메인으로 옮긴다.

admin 체계:

- root admin 1명은 시드로 만든다. root는 첫 admin일 뿐 권한 차이 없다
- admin이 BO에서 초대 링크를 만들어 복사해 전달한다. 메일 발송 없음
- 초대받은 사람이 링크에서 아이디·비밀번호를 정하면 admin이 된다
- admin은 전부 같은 권한이다
- BO 로그인과 MCP 호출은 admin JWT만. MCP는 문항·퀴즈 추가 도구만 노출한다

## 4. FO 화면

탭 5개. 시험지·결과는 탭 밖 스택 화면이다.

1. **홈** — 진행 중 세션 이어하기 카드, 오늘의 퀴즈, 최근 발행 회차. 탭해야 시험으로 간다. 자동 이동 없음.
   - 오늘의 퀴즈: OX·빈칸·영단어·한국사 4종. 10문제 1세트, 문항마다 즉시 정오. 시간 제한 없음. 영단어는 en→ko / ko→en 번갈아 노출.
2. **자료실** — 발행된 시험지 전체 목록. 수능·모의 회차 카드.
3. **저장** — 북마크한 회차. 로컬 저장, 서버 없음.
4. **복습** — 채점 끝난 세션 목록. 정오와 내 답 다시보기. 로컬 SQLite.
5. **마이** — 계정 정보, 로그아웃.

스택 화면:

- **시험지** — 태블릿은 왼쪽 지문(이미지), 오른쪽 선지. 폰은 지문 위·선지 아래 세로 배치. 펜 밑줄, 채점, 남은 시간은 공통.
- **결과** — 이 장의 정오. 다음 장으로 가지 않으면 끝.

상태: `idle` → `grading` → `graded` / `aborted`. 복원 중 `restoring`이면 선지를 받지 않는다.

기본 실행은 실제 회차 1장이다. 긴 지문, 늦은 채점, 중복 목록, 프로세스 종료는 같은 코드 경로의 테스트다.

---

## 5. BO 화면

1. 로그인 (아이디·비밀번호)
2. 관리자 초대 (링크 생성 → 복사)
3. 시험지 목록·생성
4. 문항 편집 (지문 영역, 선지, 정답)
5. 퀴즈 편집 (type, 프롬프트, 선지, 정답)
6. 발행 / 숨김

FO가 보는 카드는 발행된 시험지만.

---

## 6. 데이터

- User
- Admin (아이디, 비밀번호 해시)
- AdminInvite (token, expiresAt, 사용 여부)
- ExamPaper (회차, 과목, 연도, 표지, 제한 시간, 발행 여부)
- Question (시험지, 번호, 지문 이미지, 프롬프트, 선지, 정답)
- ExamSession (user, paper, deadlineAt, status)
- Answer (session, question, choice, gradeRunId)
- Stroke (session, question, 좌표) — 기기 로컬 우선, 서버는 초안 백업만
- Quiz (type `ox | cloze | word | history`, prompt, choices 2~6, answer, direction)
- QuizSession (user, quizSet, status) — deadline 없음

채점은 서버 정답과 `gradeRunId`로 한다. 늦은 응답은 버린다.

---

## 7. 범위

하는 것

- 회차 1개 이상 실제 기출
- 한 장 풀기, 펜, 채점, 시계, 같은 기기 복원
- BO 발행
- TestFlight / 내부 배포 한 빌드

안 하는 것

- AI 코치, 해설 LLM
- 오답노트 소셜, 랭킹
- 오르조 클래스 LMS
- 한능검·공무원·LEET
- 다중 기기 동기화를 1차 완료 조건으로 두지 않음

---

## 8. 슬링 서류에 남는 문장

한장은 오르조의 핵심 루프를 제품으로 만든 앱이다. 지문이 밀려도 선지가 그대로고, 펜이 스크롤을 먹지 않고, 취소한 채점이 다음 답을 덮지 않고, 나갔다 돌아와도 같은 장이다. 운영은 BO에서 시험지를 발행한다.

---

## 9. 완료

- FO에서 발행된 시험지 한 장을 처음부터 채점까지 끝낸다
- 제출 전 재실행 시 같은 장, 같은 답, 남은 시간
- BO에서 올린 문항이 FO 목록에 나타난다
- 목록은 탭 없이 시험으로 가지 않는다
